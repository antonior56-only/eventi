Eventi in Città

Guida completa alle funzioni, all’installazione e all’uso dell’app.

Requisiti: per le ricerche Gemini, le mappe interattive e l’installazione PWA apri l’app dal suo indirizzo HTTPS su GitHub Pages. Il file aperto direttamente dal computer (file://) consente l’uso locale delle funzioni e dei dati già salvati, ma non può registrare un service worker né caricare la mappa interattiva OpenStreetMap.

1. Inserire e conservare la chiave API

Premi il pulsante API Key nell’intestazione, oppure il collegamento la tua chiave API personale nel riquadro giallo. Inserisci o aggiorna la chiave e premi Salva API key: viene conservata nel browser e nel dominio correnti. Il collegamento “Ottieni una chiave API in Google AI Studio” apre la pagina ufficiale per crearla.

Ogni utente deve inserire la propria chiave. La chiave resta nel browser dell’utente e le richieste consumano la sua quota Gemini; non inserirla nel repository e non condividerla. Quando l’app viene spostata dal file locale a GitHub Pages, il nuovo dominio ha una memoria browser distinta: potrebbe essere necessario inserire di nuovo la chiave una volta.

2. Cercare gli eventi

  • Città di riferimento: indica la città da cui partire. L’ultima scelta viene ricordata sul dispositivo.
  • Raggio indicativo: suggerisce a Gemini l’area da esplorare. Non è un filtro rigido; in mappa le distanze possono essere stimate quando le coordinate sono disponibili.
  • Categoria: seleziona una categoria preferita o lascia “Tutte le categorie”.
  • Modalità veloce: usa una richiesta Gemini e termina prima, con una ricerca meno estesa.
  • Modalità standard: esegue tre ricerche tematiche in sequenza e può richiedere più tempo e quota.
  • Periodo: limita gli eventi ai prossimi 7, 14 o 30 giorni.
  • Numero massimo complessivo: dopo aver unito e deduplicato i risultati, l’app mostra al massimo il numero scelto.

Premi Cerca eventi. Se la stessa combinazione di città e filtri è già stata cercata in giornata, l’app può riusare i risultati salvati senza chiamare Gemini. Aggiorna ignora questa cache e avvia una nuova ricerca.

Il contatore di quota è una stima locale del browser, non il dato ufficiale dell’account Google. I tentativi ritentati dopo errori possono consumare richieste aggiuntive. Per quota e limiti effettivi consulta Google AI Studio.

3. Leggere i risultati e verificare le fonti

Ogni scheda mostra titolo, data, orario quando disponibile, luogo, categoria, descrizione e indicazione sullo stato della fonte. L’app apre un link diretto solo se il collegamento è presente nei risultati Google e il titolo della pagina è compatibile con l’evento. Negli altri casi Cerca la fonte o Altri dettagli aprono una ricerca web per titolo, luogo e città. Verifica sempre data, organizzatore, luogo e disponibilità con la pagina dell’organizzatore: i risultati automatici possono essere incompleti o cambiare.

4. Viste, filtri e preferiti

  • Eventi: schede degli appuntamenti trovati.
  • Calendario: raggruppa gli eventi per giorno; il titolo apre la fonte verificata oppure una ricerca web.
  • Mappa: mostra i marker quando le coordinate si trovano. Se l’app è aperta da GitHub Pages HTTPS, usa la mappa interattiva. Nel file locale mostra le schede con link alla mappa per evitare i riquadri bloccati.
  • Preferiti: premi la stella su una scheda per salvare o rimuovere un evento. I preferiti restano nel browser e nell’origine corrente.
  • Archivio ricerche: conserva fino alle ultime 20 ricerche riuscite sul dispositivo. “Apri” ripristina gli eventi archiviati; “Elimina” rimuove una ricerca e “Svuota archivio” elimina l’intero archivio.
  • Importa file JSON: aggiunge all’archivio gli eventi esportati dall’app oppure le ricerche contenute in un oggetto o elenco con campo events. Il file deve contenere titoli e date riconoscibili. L’importazione conserva fino a 20 ricerche e i collegamenti importati vengono trattati come non verificati.

La barra dei filtri permette di cercare parole in titolo, luogo e descrizione, e filtrare per categoria o giorno. Svuota la parola chiave e reimposta i menu per tornare a tutti i risultati.

5. Condivisione ed esportazione

  • WhatsApp: prepara un testo con gli eventi attualmente visibili e apre WhatsApp/Web.
  • JSON: scarica i dati degli eventi visibili in formato JSON.
  • Calendario ICS: scarica un file importabile nei calendari. Gli eventi con orario hanno durata indicativa di due ore; quelli senza orario vengono esportati come eventi di giornata intera.
  • Stampa / PDF: apre la stampa del browser; scegli “Salva come PDF” nella destinazione.

6. Installare la PWA

Apri l’app dal suo indirizzo HTTPS. Il pulsante Installa app appare solo quando il browser conferma che può avviare l’installazione; resta nascosto quando l’app è già aperta nella finestra PWA. Su iPhone/iPad, in Safari usa Condividi → Aggiungi alla schermata Home. Se non compare il pulsante, usa il menu del browser per installare o aggiungere l’app alla schermata Home. La disponibilità dipende da browser e dispositivo.

La PWA apre l’app in una finestra autonoma e conserva i dati sul dispositivo. La cache offline contiene la pagina, il manifest, le icone e questo manuale; le ricerche nuove, la geocodifica, le mappe e le librerie caricate da CDN richiedono connessione. Gli ultimi risultati e le preferenze già memorizzati possono restare disponibili offline.

7. Aggiornamenti

Quando viene pubblicato un service worker nuovo, il browser lo scarica in background. L’app mostra il riquadro È disponibile una nuova versione. Premi Aggiorna ora per attivarla e ricaricare l’app; Più tardi rimanda l’aggiornamento. Il controllo viene ripetuto all’apertura, quando la finestra torna attiva, alla riconnessione e periodicamente mentre è aperta. Se l’avviso non appare, controlla di aver pubblicato tutti i file, incrementato CACHE_VERSION e ricarica l’app quando sei online.

8. Risoluzione dei problemi

  • Errore API o chiave: riapri il pannello API, verifica la chiave e lo stato/limite del progetto in AI Studio.
  • Quota superata: attendi il ripristino del limite o controlla quota e piano dell’account. Il contatore locale è soltanto indicativo.
  • Mappa bloccata nel file locale: è previsto; usa la versione HTTPS pubblicata su GitHub Pages.
  • Installazione non disponibile: apri l’indirizzo HTTPS, aggiorna il browser e prova il menu “Installa app”.
  • Nuova versione non rilevata: verifica i file pubblicati e CACHE_VERSION, poi riapri l’app online. Il browser può mantenere la versione attuale finché non attivi “Aggiorna ora”.
  • Archivio vuoto: l’archivio è locale al browser e all’indirizzo dell’app; non si sincronizza fra dispositivi o fra file:// e GitHub Pages.

Privacy pratica: l’app salva chiave API, città, cache, preferiti e archivio nel browser. Usa il tuo dispositivo personale e non inserire la chiave API in file o repository pubblici.

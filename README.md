# Eventi in Città – PWA

Questa cartella è pronta per GitHub Pages. Pubblica **tutti** i file e la cartella `icons` mantenendo la struttura. Configura GitHub Pages in **Settings → Pages** e apri l’indirizzo HTTPS risultante.

Apri `manuale.html` per la guida dettagliata. Per ogni nuova release, incrementa `CACHE_VERSION` in `service-worker.js`: gli utenti vedranno l’avviso di aggiornamento. L’app richiede la chiave API Gemini personale di ciascun utente; non inserirla nel repository.
